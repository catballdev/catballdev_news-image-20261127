# catballdev News Image

This repository contains a news image entry for the catballdev project.

## Files

- `main.py` - Main entry point that copies `entry.png` to `news.png`
- `draw_entry.py` - Script to generate the news image
- `entry.png` - Generated news image

## Usage

```bash
python3 main.py
```
